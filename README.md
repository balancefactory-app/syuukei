# syuukei

Loyverse の**前日売上**をカテゴリ別に集計し、Google スプレッドシートへ**自動で**書き込む Google Apps Script（GAS）です。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `コード.gs` | 集計本体。Loyverse API からレシートを取得し、カテゴリ別にシートへ書き込む。自動実行トリガーの設定/解除も含む。 |
| `appsscript.json` | プロジェクト設定。タイムゾーンを `Asia/Tokyo` に固定（トリガー時刻を JST 基準にするため）。 |

## 何ができるか

- **毎朝 6 時台**にスクリプトが自動で起動し、**前日 1 日分**の売上を集計してシート `伝票 入出金` の該当日行へ書き込みます。
- 集計の実行履歴（対象日・レシート件数・未分類商品・除外レシート）は `集計ログ` シートに自動追記されます。
- 手動での「今すぐ実行」「過去日の再集計」も可能です。

## セットアップ手順

1. スプレッドシートを開き、**拡張機能 → Apps Script** を開く。
2. `コード.gs` と `appsscript.json` の内容を貼り付けて保存する。
   - `appsscript.json` はエディタ左の歯車（プロジェクトの設定）で「`appsscript.json` マニフェスト ファイルをエディタで表示する」を ON にすると編集できます。
3. スクリプトエディタ上部の関数選択で **`setupDailyTrigger`** を選び、一度**手動実行**する。
   - 初回のみ Google の**承認画面**が出るので許可してください（これで自動実行トリガーが登録されます）。
4. 以降は毎朝 6 時台に自動で前日分が集計されます。

## スプレッドシートのメニューからの操作

スプレッドシートを開くと、上部に **「売上集計」メニュー**が追加されます。

- **前日集計を今すぐ実行** … 手動でその場で前日分を集計
- **自動実行を ON（毎朝6時台）** … 自動トリガーを登録（`setupDailyTrigger`）
- **自動実行を OFF** … 自動トリガーを解除
- **自動実行の状態を確認** … 現在 ON / OFF かを確認

## 実行時刻を変えたい場合

`コード.gs` 先頭の定数を変更し、再度メニューの「自動実行を ON」を実行してください（既存トリガーを消して作り直します）。

```js
const TRIGGER_HOUR = 6; // 0〜23（JST）。例: 5 にすると毎朝5時台
```

## 過去日の再集計

スクリプトエディタから直接実行します。

```js
shukeiForDate(2026, 8, 13); // 2026/08/13 を再集計
```

## 補足・注意

- `TOKEN` は Loyverse の API トークンです。公開リポジトリに含めたくない場合は
  スクリプトプロパティ等への退避を検討してください。
- 集計対象の行は `伝票 入出金` シートの B 列（2 列目）の日付で照合します。該当日の行が
  無い場合は書き込まれず、`集計ログ` にその旨が残ります。
- カテゴリと書き込み先の列は `コード.gs` の `CAT_COL` で定義しています。
