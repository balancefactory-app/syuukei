# syuukei — 入出金 自動仕分けアプリ

現金・銀行などの入出金を**入力するだけ**で、Google スプレッドシートの該当シートへ
**自動的に仕分けして落とし込む**アプリです。Google スプレッドシート＋Google Apps Script (GAS) で動作します。

## できること

- 入力項目：**日付 / 金額 / 入出金先名 / 現金・振込 / 入金・出金 / 仕分け項目 / メモ（任意）**
- **入出金先名はプルダウン（＋新規入力）**。一度登録した先は候補に自動追加。
- 入出金先を選ぶと、**現金/振込・入金/出金・仕分け項目が既定値として自動入力**（違う場合は手動で選び直せます）。
- **「現金/振込 × 入金/出金」の組み合わせで 4 シートへ自動振り分け**：

  | | 入金 | 出金 |
  |---|---|---|
  | **現金** | 現金売上明細 | 現金出金明細 |
  | **振込** | 銀行＆郵便局入金 | 銀行＆郵便局出金 |

- データは全項目を各シートへ保存するので、**先々の集計・解析シートを後付けしやすい**構造です。

## ファイル構成

```
apps-script/
  ├─ Code.gs          … サーバー側ロジック（振り分け・マスタ学習・セットアップ）
  ├─ index.html       … 入力フォーム（プルダウン・自動入力）
  └─ appsscript.json  … GAS プロジェクト設定（タイムゾーン Asia/Tokyo 等）
```

## 導入手順（コピペで約 10 分）

1. **スプレッドシートを新規作成**
   [https://sheets.new](https://sheets.new) を開き、名前を「入出金台帳」などに変更。

2. **Apps Script を開く**
   メニュー **拡張機能 → Apps Script** をクリック。

3. **コードを貼り付け**
   - 既定の `コード.gs` を開き、中身をすべて消して `apps-script/Code.gs` の内容を貼り付け。
   - 左の **＋ → HTML** で `index` という名前のファイルを作成し、`apps-script/index.html` の内容を貼り付け（拡張子 `.html` は自動で付きます）。
   - （任意）プロジェクト設定で「`appsscript.json` を表示」を有効にし、`apps-script/appsscript.json` の内容に合わせるとタイムゾーンが日本時間になります。

4. **初期セットアップを実行**
   - エディタ上部の関数一覧で **`setup`** を選び、**▶ 実行**。初回は権限の承認を求められるので許可してください。
   - スプレッドシートに戻ると 4 つの明細シートと「入出金先マスタ」が作成されています。
   - （以降はスプレッドシートのメニュー **「入出金アプリ」→「初期セットアップ」** からも実行できます。）

5. **Web アプリとして公開**
   - Apps Script の右上 **デプロイ → 新しいデプロイ**。
   - 種類の選択（歯車）で **ウェブアプリ** を選択。
   - 「次のユーザーとして実行」= **自分**、「アクセスできるユーザー」= **自分のみ**（単独利用のため）。
   - **デプロイ** → 表示される **ウェブアプリの URL** をブックマーク。これが入力画面です。

6. **使う**
   URL を開き、日付・金額・入出金先名などを入力して「登録する」。
   自動で該当シートに 1 行追加され、入出金先はマスタに学習されます。

## よくあるカスタマイズ

- **シート名を変えたい / 増やしたい** … `Code.gs` 冒頭の `SHEETS` を編集。
- **保存する列を増やしたい** … `DETAIL_HEADERS` を編集（`submitEntry` の `row` も合わせて調整）。
- **入金/出金を毎回手で選びたい** … 既定で手動選択できます。自動入力を止めたい場合は
  `index.html` の `applyDefaults()` から `flow`（や `kind`）の行を外してください。
- **複数人で使いたくなったら** … デプロイの「アクセスできるユーザー」を変更し、入力者列の追加を検討してください。

## 注意

- 金額は 0 以上の数値のみ。日付は `YYYY-MM-DD` 形式で保存されます。
- マスタの既定値は「最後に登録した内容」で上書き更新されます（入出金先の扱いを変えたいときはその先で一度登録し直せば既定値が更新されます）。
